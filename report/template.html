gdal-r-ci image report

What is in each published image, how big it is, and whether the one-library-per-process invariants hold.

Summary

Compressed = registry download size (layers + config, linux/amd64). On disk = uncompressed image size after pull. Census = shared libraries mapped in one process after loading the stack (R packages plus Python via reticulate where R is present); "dup" lists libraries mapped from more than one file. Strip = shared objects in /usr/local/lib and the R site-library that still carry DWARF debug info.

Method

Each image is pulled on a GitHub-hosted runner and probed from the inside by report/image-report.py (stdlib only, run with the image's own /opt/gdal-py interpreter). Registry sizes come from the image manifest; the size history is recovered from earlier GHCR package versions by digest, with the variant read from the image history (GDAL_VERSION=master marks :dev in the Docker chain, the ENV=dev build arg in gdal-conda). Raw data: latest.json, history.jsonl, ghcr.json, canary.json. Source: report/.
